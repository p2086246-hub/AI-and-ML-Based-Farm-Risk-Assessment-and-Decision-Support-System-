# What changed in AgriTech V7

V7 consolidates the requested final changes into a clean new-folder release.

## Branding
- New custom AgriTech Smart Farm Intelligence logo on login, sidebar, header and favicon.

## Location and map
- Location autocomplete with exact-coordinate selection.
- Weather loads immediately after selecting a location.
- Google Maps preview is the default.
- OpenStreetMap backup can be selected if Google embed is blocked.
- Direct Google Maps link remains available.
- Farm save requires a resolved coordinate so live-weather farms are not accidentally saved with an ambiguous text-only location.

## Plant treatment
- Detailed problem explanation.
- Visible symptom interpretation.
- Possible causes.
- Immediate non-chemical actions.
- Prevention steps.
- Chemical/pesticide category only when justified.
- Reason for the chemical category.
- Explicit “when not to spray” conditions.
- Label/PPE/registration warning and official verification link.

## New differentiating features
- Disease Progress Tracker.
- What Changed? risk comparison.
- Smart Action Calendar with completion tracking.

## History
- Assessment date and local time.
- Farm name, risk, confidence and source.
- Last 7 days / last 30 days / all filters.
